Review of the inlined material, ordered by severity. I could not run tests or inspect the non-inlined subject files.

1. **High — Profile access is not separated by student.** [app.py: profile routes](/data/zhoutaichang/live-agent/live_agent/server/app.py) exposes list, read, edit, and reset routes without a caller check in the shown code; the included API test accesses them without a token. An HTTP client can enumerate and alter every allowed profile. A shared token would still give every holder access to every allowed ID. **Fix:** authenticate these routes and authorize each student ID and action; restrict teacher-only edits and resets.

2. **High — Common grade text selects the wrong teaching level.** [curriculum.py:parse_grade](/data/zhoutaichang/live-agent/live_agent/curriculum.py) parses “初中二年级” as **2** and “高中一年级” as **1** because the stage regex misses “中”, then the generic “二年级/一年级” regex wins. The planner consequently adopts a primary-school role, teaching profile, and curriculum grade. “九年级”, “十年级”, and “二年级下” parse as expected; “大一” and “幼儿园” return unknown. Free text can also pick an incidental “高一” before the student’s own grade. **Fix:** parse explicit stage forms first, require an unambiguous grade expression, and normalize or reject grade input at the API boundary.

3. **High — Reset can erase new work and can be undone by an in-flight lesson.** [app.py:reset_student](/data/zhoutaichang/live-agent/live_agent/server/app.py) accepts no version, unlike PUT. A stale editor can reset a profile just after a graded exercise. [student.py:ProfileStore.reset](/data/zhoutaichang/live-agent/live_agent/student.py) replaces the shared object but does not advance the orchestrator’s profile/input epochs or cancel pending grading; a result completing afterward can write into the reset profile. Reset also immediately saves the seed again, despite its “delete saved profile” description. **Fix:** require a current version for reset, serialize it with grading, invalidate pending profile-dependent work, and define whether reset should leave a saved file.

4. **High — A lexical hit can confidently identify the wrong chapter.** [curriculum.py:lookup/locate](/data/zhoutaichang/live-agent/live_agent/curriculum.py) says English matching uses whole words, but the later substring rule marks “Art” inside grade-9 **“Smart Learning”** as a 0.9 match. For a grade-9 student it can outrank grade-12 “Art”; `locate` then skips the model because 0.9 is treated as strong. A grade-7 lesson titled “三角形” similarly flags the topic as generally taught in grade 8, although the inlined math data also teaches triangles in grade 4. Single-character topics such as “圆” are discarded by `lookup`. **Fix:** use word boundaries for Latin text, require stronger evidence for short strings, and suppress above/below-grade notes when a concept recurs across grades or the requested scope is unclear.

5. **Medium — A real chapter is accepted even when unrelated to the requested topic.** [curriculum.py:_entry/locate](/data/zhoutaichang/live-agent/live_agent/curriculum.py) verifies only that the model named a plausible chapter in the claimed grade. For “根号的化简”, a model pick of the real grade-8 chapter “勾股定理” passes and receives `sim=0.95`; the planner can then receive its prerequisites, requirement, and grade note as though relevance were verified. A short partial chapter name can also pass `_entry`. **Fix:** use exact chapter IDs from the index and separately validate relevance to the query; do not assign high similarity merely because the chapter exists. Validate the parsed JSON’s top-level type as well—`.get()` on a list currently escapes the local `ValueError` handler.

6. **Medium — Requirement matching can attach a true but irrelevant standard statement.** [curriculum.py:_requirements](/data/zhoutaichang/live-agent/live_agent/curriculum.py) accepts 50% query-bigram overlap and takes the maximum against either the query or a broad chapter title. “三角形面积” can match the grade-4 “三角形（特性、分类、内角和）” chapter and attach the stage requirement about recognizing and classifying triangles, rather than area. The output labels it “课标要求”. **Fix:** match a requirement to the specific asked skill, keep chapter similarity separate, and omit requirements when evidence is weak.

7. **Medium — High-school course categories are presented as fixed national grade assignments.** [curriculum.py:_render](/data/zhoutaichang/live-agent/live_agent/curriculum.py) turns a stage’s estimated `[11,12]` mapping into “课标高二至高三”. In [math.json](/data/zhoutaichang/live-agent/configs/curriculum/math.json), choosing grade 12 for 选择性必修第三册 and “高考总复习” is described in notes as an arrangement or estimate, yet the grade’s `basis` is `textbook`. This can produce a false “above grade” warning for a school teaching that module earlier. The ministry describes 必修、选择性必修、选修 as course categories, not a universal year-by-year sequence. [MOE course explanation](https://www.moe.gov.cn/jyb_xxgk/xxgk_jyta/jyta_jiaocaiju/202107/t20210729_547567.html) **Fix:** store standard stage/category separately from local or estimated teaching year, label estimates per topic, and do not issue firm grade warnings from estimated mappings.

8. **Medium — Concept “delete” and “clear” do not consistently produce the UI’s promised result.** [student.py:edit_concepts/view/mastery](/data/zhoutaichang/live-agent/live_agent/student.py) removes a concept object, but `view()` adds every exam weak point back to the displayed concept set. Clearing its mastery can likewise reveal the exam-derived 0.4 estimate, while [profile.html:renderConcepts](/data/zhoutaichang/live-agent/live_agent/server/static/profile.html) says it will become unassessed. Clearing `history` leaves attempts, correctness counts, misconception notes, and current mastery intact. **Fix:** define separate actions for deleting a record, clearing an estimate, and erasing exercise evidence; implement and label each consistently, including exam-derived records.

9. **Medium — API validation is weaker than the editor suggests.** [app.py:put_student](/data/zhoutaichang/live-agent/live_agent/server/app.py) takes an unrestricted dictionary; browser `maxlength` and numeric controls do not protect direct requests. [student.py:edit_concepts](/data/zhoutaichang/live-agent/live_agent/student.py) creates a concept *before* discovering an invalid mastery value, truncates names (which can collide), clamps out-of-range mastery silently, and has no visible edit-count limit. An invalid `"mastery":"oops"` can therefore leave a new, unassessed concept after a successful save. **Fix:** validate a bounded request schema, finite mastery in `[0,1]`, canonical grade, and exam fields before mutating a copy of the profile; commit only after all fields pass.

10. **Medium — Locator input and caching create avoidable latency and persistent bad picks.** [curriculum.py:locate/LOCATE_PROMPT](/data/zhoutaichang/live-agent/live_agent/curriculum.py) sends the full reported 16k-character index on each uncached lesson start, with no in-flight deduplication; concurrent identical topics can make duplicate calls. The cache keeps only three grade-agnostic model picks under the normalized topic, so a poor selection is reused for every student grade. Raw topic text is also inserted into the locator prompt and, on a standard-only hit, echoed into the planner’s curriculum block; a topic containing newlines and instructions can impersonate reference text. **Fix:** bound topic length, use explicit data boundaries, avoid echoing raw topic as trusted curriculum, cache validated candidates with enough coverage to rank by grade, and coalesce concurrent lookups.

11. **Medium — Grade guidance conflicts with the spoken-line contract and loses evidence labels.** [lesson.py:_curriculum_block/section](/data/zhoutaichang/live-agent/live_agent/lesson.py) and [curriculum.py:teaching_context/clean](/data/zhoutaichang/live-agent/live_agent/curriculum.py) put the full guidance into outline and section prompts; [orchestrator.py:_student_context](/data/zhoutaichang/live-agent/live_agent/orchestrator.py) adds it again to ongoing decisions. Grades 8–12 recommend roughly 24–30 characters per sentence while the demo requires at most 22 spoken Chinese characters. `clean()` removes source tags, and the prompt does not distinguish cited requirements from editorial timing and content advice. **Fix:** make the 22-character spoken limit explicit and dominant, adapt sentence advice to that limit, shorten repeated context, and carry evidence labels into planning without asking the teacher to speak citations.

12. **Medium — Some grade-level and evidence claims are more precise than their support.** [pedagogy.json](/data/zhoutaichang/live-agent/configs/curriculum/pedagogy.json) places “累计识字约3000字” in grade 5, while its cited source description identifies that figure as an **end-of-third-stage** target, covering grades 5–6. Per-grade interaction intervals, point counts, and sentence lengths appear as direct instructions; only the file’s closing notes label them estimates. The Wikipedia Piaget summary is marked `kind:"research"`, which overstates its source type. **Fix:** label each numerical claim where it appears as cited, locally measured, estimate, or proposed target; correct stage-end claims; classify secondary summaries as secondary sources.

13. **Medium — Version protection is only process-local.** [student.py:ProfileStore](/data/zhoutaichang/live-agent/live_agent/student.py) holds one profile and version per Python process. With two server workers, each can load the same version, accept an edit, and overwrite the same JSON file; `_SAVE_LOCK` protects threads within one process only. **Fix:** enforce a single-worker deployment for this demo or move profiles and version comparison to transactional shared storage.

14. **Low — The validator can report success with broken provenance.** [check_curriculum.py:check_subject](/data/zhoutaichang/live-agent/tools/check_curriculum.py) treats a missing source URL and missing grade topics as warnings, and checks source IDs for only some structures. A subject with an uncited requirement or a missing required grade can exit successfully while the summary looks complete. **Fix:** distinguish documented intentional gaps from errors, require resolvable per-claim provenance, and validate all cited structures and basis values.
