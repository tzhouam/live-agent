Record text is exact logged input and planned scripts, labelled as unverified against audio and possibly containing unplayed words. Known partial requests are omitted; full-chunk-ACK and unknown evidence remain distinct. This aid is not captions or an audio equivalent. Unknown legacy attribution is excluded from student-scoped views. Scoped navigation does not add authentication or secure account isolation to the existing trusted local service. The English edition translates interface labels; school catalogue/teacher language remain Chinese, and university course coverage is unavailable.

Every successful browser text submission and voice `speech_start` carries a unique request ID. Backend
IDs remain optional for legacy packets; voice ASR carries the recording-start ID and input epoch.
Lesson/exercise activity events carry optional `data.request_id`; pending exercise state carries `exercise.request_id`.
Close, grading and timeout preserve the creating exercise's owner, while answer utterance events carry the
answer's ID. Only correlated decision events add `applied`; false denotes superseded work. The frontend
rejects retired/mismatched activity owners before changing status or answer controls. Activity buttons
are blocked through pending/generated/open practice. `exercise_existing` is keyed to the current input
and carries `exercise_request_id` for the original creator, restoring the actual question without new
generation or creator mutation. Ordinary answers have unique input IDs while grading and close retain
the creator. The latest input candidate is separate from that creator; a matching nonnull activity
event or exercise snapshot adopts a replacement lesson. Newer input and matching terminal outcomes
retire the candidate. Decision-property presence or `applied: false` triggers null-safe cleanup, covering
null/false decisions and missing decisions with `applied: false` for matching candidates and pending
lesson/practice requests. Panel errors retire only the matching pending request ID; unrelated, missing or
null IDs are ignored. Global session failure retains the existing connection lifecycle. Padded catalogue
titles are normalized before selection and lesson/practice packet construction. Uncorrelated compatibility
is retained.
